Ask my AI.

Ask about my work, my stack and what I've shipped. It answers only from my resume and technical profile. It can't browse the web, and it says so when it doesn't know.

Resume data only No web access No guessing
// ANIL.AIanswers from resume only
HOW IT WORKS
Your question goes to a small server function that asks an AI model to answer using only the facts in my resume profile. If that service is down or busy, the page falls back to a built-in matcher over the same facts. Nothing is pulled from the web.
OUT OF SCOPE
Questions outside my work, such as general knowledge, news or writing code for you, get a polite no. Personal details I haven't published, like salary, get a pointer to contact me.
